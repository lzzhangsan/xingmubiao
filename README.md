# 星目标 - 儿童习惯养成应用

这是一个基于Flutter开发的儿童习惯养成应用，旨在帮助3-12岁儿童通过积分制激励系统培养良好习惯和自律能力。

## 应用特色

- **积分制激励系统** - 通过积分奖励机制激励孩子完成目标
- **评分式打卡** - 独特的评分式打卡功能，专为儿童设计
- **目标管理** - 支持自定义目标设置和阶段性目标管理
- **数据分析** - 提供丰富的数据统计和分析功能
- **心愿库** - 孩子可以通过积分兑换心愿
- **家庭共享** - 支持多家庭成员协作管理

## 技术栈

- Flutter - 跨平台移动应用开发框架
- Firebase - 后端即服务(BaaS)
- Dart - 编程语言

## 功能模块

1. 用户认证系统
2. 目标管理系统
3. 打卡评分系统
4. 积分管理系统
5. 心愿库系统
6. 数据统计和可视化
7. 家庭共享功能

## 开始开发

1. 确保已安装Flutter开发环境
2. 运行 `flutter pub get` 安装依赖
3. 配置Firebase项目
4. 运行 `flutter run` 启动应用
